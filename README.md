## Git hygiene

The repository ignores local virtual environments, Python/Jupyter caches, temporary files, and per-user editor workspace files. Project notebooks, input data, and generated deliverables remain eligible for version control.

Before committing, review `git status` and stage only the intended project files. `.gitignore` prevents matching untracked files from being added, but it does not remove files that are already tracked.
